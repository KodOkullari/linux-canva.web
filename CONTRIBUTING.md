# Contributing

Contributions are welcome, especially reproducible tests from different Linux
desktop environments and official Brave packaging formats.

Before opening a pull request run:

```bash
./tests/run.sh
```

Keep the helper dependency-light and auditable. Do not add:

- Canva or Brave logos, binaries, screenshots, or copyrighted design content;
- cookies, tokens, profiles, account data, designs, or diagnostic archives;
- scraping, DOM injection, account automation, upload/download automation, or reverse-engineered APIs;
- automatic root actions, browser installation, profile migration, or data deletion.

Document user-facing behavior in both the English README and Turkish guide.
New destructive actions are out of scope.
